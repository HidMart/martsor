نصب

آخرین نسخه martsor:

pip install martsor

نصب نسخه 0.2.0:

pip install martsor==0.2.0

martsor برای Python 3.8 و بالاتر طراحی شده است.

شروع سریع

import martsor

bot = martsor.Bot("TOKEN")

@bot.on_command("start")
async def start(update):

    await bot.send_message(
        update.chat_id,
        "سلام! ربات فعال است."
    )

bot.run()
نکته امنیتی

Token ربات خود را داخل GitHub یا کد عمومی قرار ندهید. برای پروژه‌های واقعی از متغیر محیطی استفاده کنید.

اجرای Bot

Handlers

Command Handler

@bot.on_command("start")
async def start(update):

    await bot.send_message(
        update.chat_id,
        "سلام!"
    )

Message Handler

@bot.on_message
async def message_handler(update):

    print(update.text)

Callback Handler

@bot.on_callback
async def callback(update):

    print(update.data)

Edited Message

@bot.on_edited_message
async def edited(update):

    print(update.text)

Keyboard

martsor از Inline Keyboard و Reply Keyboard پشتیبانی می‌کند.

Inline Keyboard

import martsor

keyboard = martsor.InlineKeyboard()

keyboard.button(
    "گزینه اول",
    callback_data="option_1"
)

keyboard.button(
    "گزینه دوم",
    callback_data="option_2"
)

await bot.send_message(
    chat_id,
    "یک گزینه انتخاب کنید:",
    reply_markup=keyboard
)

URL Button

keyboard = martsor.InlineKeyboard()

keyboard.url(
    "وب‌سایت",
    "https://example.com"
)

Reply Keyboard

keyboard = martsor.ReplyKeyboard([
    ["گزینه اول", "گزینه دوم"],
    ["گزینه سوم"]
])

await bot.send_message(
    chat_id,
    "انتخاب کنید:",
    reply_markup=keyboard
)

حذف Keyboard

keyboard = martsor.ReplyKeyboardRemove()

await bot.send_message(
    chat_id,
    "کیبورد حذف شد.",
    reply_markup=keyboard
)

مدیریت خطاها

خطاهای API توسط استثنای APIError مدیریت می‌شوند. 

import martsor

try:

    bot.send_message(
        chat_id,
        "Hello"
    )

except martsor.APIError as error:

    print(error)

Retry

در صورت دریافت خطای 429، کتابخانه می‌تواند با توجه به مقدار retry_after درخواست را دوباره تلاش کند.
